# پپتیدیار

دانشنامهٔ آموزشی و دوزبانه برای نام‌های یک فهرست پژوهشی: پپتید، قرص، روغن تزریقی و پودر خام. فروش، قیمت، دوز و روش مصرف ندارد.

بسیاری از این نام‌ها در بریتانیا و اتحادیه اروپا داروی مجاز نیستند. برخی استروئیدهای آنابولیک داروی کنترل‌شده‌اند. مطالب سایت توصیهٔ پزشکی نیست.

شمار قلم کالا در فهرست تجاری مبدأ (۱۷۹، ۷۹، ۶۷ و ۲۰۴) با شمار ماده یکی نیست. جمع آن چهار عدد ۵۲۹ است. این دانشنامه هر نام شیمیایی را یک بار نگه می‌دارد و برای رسیدن به رقم ۵۴۷ نامی نمی‌سازد.

## اجرا

Node.js لازم است.

```bash
npm install
npm run dev
```

سرور توسعه روی `0.0.0.0:43123` بالا می‌آید: [http://127.0.0.1:43123](http://127.0.0.1:43123)

نسخهٔ ایستا:

```bash
npm run build
```

خروجی در پوشهٔ `out/` است. نشانی کانونیکال در `src/lib/site.ts` تا زمان وصل دامنه یک جایگزین است.

زبان پیش‌فرض فارسی است. دکمهٔ EN در سربرگ انگلیسی را روشن می‌کند و انتخاب در مرورگر می‌ماند.

## افزودن یا ویرایش مونوگراف

مونوگراف‌ها در `src/lib/catalog/monographs.ts` هستند و کلیدشان همان `slug` مدخل در کاتالوگ است.

- هر مقاله باید `pmid` و `doi` داشته باشد و هر دو با خود PubMed تطبیق داده شده باشند. عنوان و سال را از PubMed کپی کنید، نه از حافظه.
- توالی فقط وقتی نوشته می‌شود که از منبع معتبر مطمئن باشید؛ در غیر این صورت فیلد `sequence` را نگذارید.
- دوز، برنامهٔ مصرف، روش رقیق‌سازی یا مسیر تهیه نوشته نمی‌شود. نتیجهٔ کارآزمایی‌ها بدون عدد دوز گزارش می‌شود.
- پس از بازبینی منابع، `monographsReviewed` را به تاریخ همان روز تغییر دهید.
